## 🌟 系統定位與核心目標

本系統整合**得到大腦知識庫「B3.1.1 精力管理_得到：怎樣成為精力管理的高手」**（張遇升 MD/MBA 醫學底層邏輯），專為 **1978 年次（現年 48 歲）** 企業高階經理人量身打造：
1. **打破時間管理陷阱**：時間是剛性的（每天 24 小時），精力卻如肌肉般可持續訓練。將身體視為 F1 賽車底盤，重塑體能、情緒、注意力與意義感四層金字塔。
2. **即時智慧檢索中心**：具備關鍵字高亮、即時篩選（海馬體、幽門螺旋桿菌、48歲、血糖、深睡、熱啟動、ONQI 等），支援一秒定位。
3. **15 頁顧問級全圖解簡報**：每一頁皆配備高解析度概念攝影圖、顧問級金字塔結構與演講逐頁精華解讀備忘錄。
4. **1978 高階經理人專章**：深度剖析 48 歲生理與高壓雙重暗礁，構建 F1 賽車底盤觀、認知帶寬保護法則、能量 ROI 投資觀，提供四大作戰 SOP。
5. **未來資料擴充架構**：具備可擴充的 JSON 資料驅動架構，支援未來無縫擴充《馮雪·科學減肥16講》、《怎樣獲得高質量睡眠》、《家庭健康100講》等系列課程。

## 👔 專章特企：1978 年次（48歲）高管三大心智模型

1. **F1 賽車底盤觀 (The F1 Chassis Philosophy)**：
   - 高管是賽車手，更是車隊經理。年度競爭如同 20 場 F1 大獎賽。
   - 獲勝關鍵在於底盤與引擎的機械可靠度，而非蠻力加班狂踩油門。定期進站保養換胎，方能持續領跑。
2. **認知帶寬保護法則 (Cognitive Bandwidth Preservation)**：
   - 高管年薪是為了每天「2~3 個牽動公司未來的關鍵戰略決策」而支付。
   - 嚴格守住前額葉頻寬，絕不容許瑣碎訊息、情緒內耗或暴飲暴食引發的低血糖奪走認知清醒度。
3. **能量 ROI 投資觀 (Energy Return on Investment)**：
   - 每天投資 1.5 小時於高品質飲食、碎片化運動、充足深睡與正念熱啟動。
   - 產出的是每週多出 20 小時具備絕對清醒度與創造力的頂級戰鬥力，ROI 高達數百倍。

- **🍷 商務應酬生存守則 (18:00-22:00)**：應酬前 30 分鐘飲水補充蛋白質護胃；酒水 1:1 溫水交換；差旅商務包備齊真絲眼罩、耳塞與彈力繩。

## 🛠️ 技術規格與部署說明

- **前端技術**：HTML5, Tailwind CSS, Phosphor Icons, Vanilla JavaScript (零建置步驟，無外部伺服器依賴)
